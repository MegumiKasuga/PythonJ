A small Python interpreter for recreational use, not intended to implement full Python functionality. Please raise any interpreter bug issues you found, it's very important to us. If you are also intrested in this project, contact us.

一个娱乐用小型Python解释器，不准备实现完整的Python功能。请在issue栏目中提出您找到的任何解释器bug, 这对我们非常重要。如果您对该项目感兴趣，请联系我们。

HOW TO USE (need java17 installed):
- Repl Mode: run the jar file directly.
- File Mode: run with `java -jar ProjectJ-xxxx-xxxx.jar your_python_file.py`

如何使用(需要已安装java17):
- 交互式模式: 直接运行jar文件。
- 文件模式: 命令行输入 `java -jar ProjectJ-xxxx-xxxx.jar your_python_file.py`
